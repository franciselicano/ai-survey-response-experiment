# AI Authorship and Survey Response Rates

A cluster-randomized experimental design examining whether AI-authored survey invitations affect student survey response rates relative to human-authored invitations.

The experiment uses matched-pair randomization across MIDS and MICS Slack cohort channels. The project includes experimental design, treatment randomization, covariate-balance assessment, simulation-based power analysis, and a planned matched-pair randomization-inference analysis.
